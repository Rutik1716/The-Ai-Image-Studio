# 🎨 AI Image Studio

An interactive AI-powered image generation application built as part of the **MirAI School of Technology – AI Builder Virtual Summer Internship 2026**.

The application allows users to enter a text prompt, select an artistic style, and generate an AI-created image using **Pollinations AI**.

## 🚀 Features

- ✍️ Text-to-image generation
- 🎨 Multiple artistic styles
- 🖼️ AI-generated images
- 💻 Interactive Streamlit interface
- ⚡ Simple and easy-to-use image generation workflow
- 🔄 Generate different images using different prompts and styles

## 🎭 Available Styles

The application supports different visual styles, including:

- 📸 Photorealistic
- 🌸 Anime
- 🏛️ Vintage Victorian
- ✏️ Sketch
- 🧊 3D Render

The selected style is combined with the user's prompt to create the image.

## 🛠️ Technologies Used

- Python
- Streamlit
- Pollinations AI
- URL-based AI image generation
